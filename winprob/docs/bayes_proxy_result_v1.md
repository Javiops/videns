## Hypothesis and what was actually computed

The experiment transfers relative evidence from causal own-project proxies:
the frozen OOF state classifier S and its fixed memory predictor M=.5S+.5R.
Retrieval remains k32, same champion, one vote per opposite-fold training game,
the original distance/temperature rule, and fixed neural checkpoints. No
encoder, optimizer, neighbor rule or epoch was refitted or selected.

From closed past purchase likelihoods, equal prior weights become posterior
weights w. The current correction is

    q(a) proportional to M2(a) * (w_S S(a)+w_M M(a))/(.5S(a)+.5M(a)).

The ordinary Bayesian proxy update has a cumulative log-loss statement for
the proxy forecaster; that statement does not protect anchored M2 or its first
recommendation. A synthetic counterexample to transferring the guarantee was
tested before real prediction. The measured result illustrates that distinction;
it does not identify the player's private intention or a causal action value.

The prefix census supplies15573real closed past visits for2613queries. All287
zero-history queries retain exact M2 in all three corrections. Synthetic SAVE
nodes are removed before counting/ordering because their existence uses future
qualification. Real ward-only visits remain. Every retained visit ends strictly
before its query; no current or future recipient-fold target enters prediction.

Native historical M2 parent forecasts were deliberately not used as the new
history channel: their final-role dependencies are uncertified at decision
time. The own causal proxies use the audited public-state allowlist. Current
native M2 remains the common reference, with its existing role/live limitation.

Training memory labels are allowed only from the opposite fold; own past labels
only from the published closed prefix. A game can legitimately be a training
game for the other OOF model. The restriction is per recipient fold, not a
misleading global assertion that no evaluation-game label is ever in any bank.
